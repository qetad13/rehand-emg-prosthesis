# ReHand v2 사용 안내

이 브랜치(`v2-only`)에는 v2 파일만 있습니다. 예전 방식(STFT + CNN)은
[`v1-stft-cnn` 브랜치](https://github.com/qetad13/rehand-emg-prosthesis/tree/v1-stft-cnn)에 있고,
문제가 생기면 그 브랜치의 `esp32_emg_realtime` 스케치와 예전 `rehand.ino`를 다시 올리면 그대로 돌아갑니다.

| | 예전 (`v1-stft-cnn` 브랜치) | v2 (이 브랜치) |
|---|---|---|
| 근전도 보드 | `firmware/esp32_emg_realtime` | `firmware/emg_board_v2` |
| 의수 보드 | `rehand.ino` | `firmware/hand_board_v2` |
| 학습 | `training/train_emg.py` | `training/train_v2.py` |
| PC에서 펌웨어 검증 | (보드에서만 가능) | `training/host_check.py` |

성능 비교와 실험 내용은 [v2_results.md](v2_results.md)에 있습니다.

> **중요**: v2 펌웨어는 Arduino로 컴파일되는 것과, 판단 코드가 PC 계산과 일치하는 것까지 확인했습니다.
> 실제 보드·의수에 올려서 움직여 보는 시험은 아직 하지 않았으므로, 처음에는 아래 "처음 올릴 때 확인 순서"를 따라 주세요.

---

## 1. 올리는 방법

Arduino IDE 설정은 예전과 같습니다: 보드 `XIAO_ESP32S3`, `USB CDC On Boot: Enabled`.

1. **의수 보드**: `firmware/hand_board_v2/hand_board_v2.ino` 열고 업로드
   - 왼손/오른손은 `HandConfig.h`에서 선택 (예전과 같음)
   - 근전도 보드와 직접 연결(ESP-NOW)됩니다. 라즈베리파이나 와이파이 공유기는 필요 없습니다.
2. **근전도 보드**: `firmware/emg_board_v2/emg_board_v2.ino` 열고 업로드 (`RUN_MODE`는 `MODE_RUN`)
   - 모델(`emg2_model.h`)은 이미 들어 있습니다. 데이터를 새로 녹화했으면 `python training/train_v2.py`로 다시 만듭니다.

두 보드는 서로를 자동으로 찾습니다(주소 입력 불필요).

**연결 상대 고정**: 의수는 처음 명령을 보낸 근전도 보드의 주소를 저장하고, 그 뒤로는 그 보드의 명령만 받습니다
(전원을 껐다 켜도 유지). 다른 보드나 근처의 다른 송신기가 보낸 명령은 버립니다.

- 처음 연결할 때는 근처의 다른 ReHand 보드를 꺼 두세요. 켜져 있으면 엉뚱한 보드와 연결될 수 있습니다.
- 근전도 보드를 다른 것으로 바꿀 때: 예전 근전도 보드를 끄고, 의수 시리얼에 `p`를 입력하거나 의수 보드의 BOOT 버튼을 3초 누릅니다.
  그다음 새 근전도 보드를 켜면 그 보드와 연결됩니다.
- 의수 시리얼의 `?`에 연결 상대 주소와 "다른 보드에서 와서 무시한 명령" 개수가 나옵니다.
- 근전도 보드는 연결된 의수가 1.5초 넘게 조용하면 다시 찾으므로, 의수를 바꿀 때는 따로 할 일이 없습니다.
- 주소만 확인하고 암호화는 하지 않습니다. 주소를 일부러 흉내 내는 송신기까지 막지는 못합니다.
- 근처에 같은 펌웨어를 올린 보드가 여러 쌍 있으면 `RehandLink.h`의 `RH_WIFI_CHANNEL`을 쌍마다 다르게(1, 6, 11) 바꾸는 것이 좋습니다.

## 2. 처음 올릴 때 확인 순서

1. **근전도 보드 자가 점검**: `RUN_MODE`를 `MODE_SELFTEST`로 올리고 시리얼 모니터를 엽니다.
   `8 / 8 통과`와 판단 1회 계산 시간이 나오면 정상입니다. 확인 후 `MODE_RUN`으로 다시 올립니다.
2. **의수 단독 시험** (근전도 보드는 꺼 둠): 의수 시리얼 모니터에서
   - `6` → 펴기, `2` → 검지, `7` → 주먹(네 손가락 먼저, 엄지 나중), `8` → 집게
   - `s30` 입력 후 `7` → 천천히 약하게 쥐기, `s100` 후 `7` → 빠르고 세게 쥐기
   - `?` → 서보 위치/전류/온도/전압 확인
   - 속도 차이가 너무 작거나 크면 `SPEED_MIN`, `SPEED_MAX`를, 쥐는 힘은 `GRIP_TORQUE_MIN/MAX`를 고칩니다.
3. **연결 확인**: 근전도 보드를 켜면 양쪽 시리얼에 `[LINK] 상대 보드 연결`이 나오고 의수 보드 LED가 꺼집니다.
4. **사용자 보정** (전극을 붙인 뒤): 근전도 보드 SW1을 3초 누르거나 시리얼에서 `c` (아래 4번 참고)
5. 평소처럼 사용

## 3. 스위치와 LED (근전도 보드)

| 조작 | 동작 |
|---|---|
| SW1 짧게 | 근전도 모드 ↔ 매크로 모드 (LED 켜짐 = 매크로 모드) |
| SW1 3초 | 사용자 보정 시작 (근전도 모드에서) |
| SW2 짧게 | 근전도 모드: **잠금 모드** 켜기/끄기 (켜면 LED 2번, 끄면 1번) / 매크로 모드: 다음 동작 |
| SW2 3초 | 의수 호밍 (LED 3번) |

시리얼 모니터에서도 같은 조작을 할 수 있습니다: `1` SW1, `2` SW2, `h` 호밍, `c` 보정, `x` 보정 지우기, `l` 잠금 모드, `?` 상태.

> 예전과 달라진 점: SW1에 "3초 누르기"가 생겨서, 모드 전환은 누르는 순간이 아니라 **뗄 때** 바뀝니다.

| LED (근전도 모드) | 뜻 |
|---|---|
| 꺼짐 | 정상 |
| 2초마다 1번 짧게 | 의수와 연결 안 됨 (의수 전원/거리 확인) |
| 2초마다 2번 짧게 | 의수 이상: 과열 / 전압 낮음 / 서보 응답 없음 (시리얼에 원인 출력) |
| 보정 중 켜짐 / 꺼짐 | 의수가 보여주는 동작 따라 하기 / 힘 빼기 |
| 6번 깜빡임 | 보정 실패 (예전 보정 유지) |

## 4. 사용자 보정 (약 40초)

전극을 다시 붙이면 채널마다 신호 크기가 조금씩 달라집니다. v2 모델은 "어느 채널이 얼마나 큰지"를 중요하게 보기 때문에,
전극을 새로 붙였으면 한 번 보정하는 것을 권장합니다. 결과는 보드에 저장되어 전원을 껐다 켜도 유지됩니다.

1. 팔을 편하게 두고 SW1을 3초 누릅니다 (또는 시리얼 `c`).
2. **의수가 동작을 하나씩 보여줍니다** (엄지 → 검지 → 중지 → 약지 → 소지 → 주먹 → 집게).
   LED가 켜져 있는 동안 같은 동작을 **평소 힘으로** 따라 하고, LED가 꺼지면 힘을 뺍니다.
3. 끝나면 LED가 2번 깜빡이고, 시리얼에 채널별 배율과 동작별 힘 세기 기준이 출력됩니다.

보정이 하는 일
- 채널별 신호 크기를 학습 데이터 기준에 맞춤 (7개 동작에서 구한 차이의 중앙값이라 한두 동작을 잘못해도 영향이 작음)
- 방금 준 힘을 동작별 "힘 세기 100%" 기준으로 저장 → 힘 세기 비례 제어가 사용자에게 맞춰짐
- 신호가 쉴 때의 1.5배도 안 되는 동작은 건너뛰고, 성공한 동작이 4개 미만이면 적용하지 않음

보정이 못 하는 일: 전극 **위치**가 많이 달라진 경우(다른 근육 위에 붙인 경우)는 보정으로 해결되지 않습니다.
이때는 새로 녹화해서 `train_v2.py`로 다시 학습해야 합니다. `x`를 보내면 보정을 지우고 학습 데이터 기준으로 돌아갑니다.

## 5. 잠금 모드

물건을 오래 들고 있을 때 계속 힘을 주고 있으면 팔이 금방 피로해집니다.
잠금 모드(근전도 모드에서 SW2 짧게)를 켜면
- 한 번 힘주면 → 그 동작으로 **유지** (힘을 빼도 그대로)
- 다시 아무 동작이나 힘주면 → **풀림** (펴기)
- 쥐는 힘은 잠글 때 가장 세게 준 힘으로 유지됩니다.

## 6. 힘 세기 비례 제어 (의수 보드)

근전도 보드가 보내는 힘 세기(1~100)에 따라
- **속도**: `SPEED_MIN`(세기 1) ~ `SPEED_MAX`(세기 100) 사이로 움직임. 펴기(6)는 항상 최고 속도
- **쥐는 힘**: 쥐는 자세(주먹, 집게, 파지 매크로)에서 서보 힘 한도를 `GRIP_TORQUE_MIN` ~ `GRIP_TORQUE_MAX`로 조절
- 움직이는 중에도 세기가 8 이상 바뀌면 같은 목표를 새 속도·힘으로 다시 보냅니다 (약하게 쥐었다가 더 세게 쥐기 가능)
- 예전의 그립 단계 명령(21~24)도 그대로 받습니다.

## 7. 의수 보드에서 달라진 점

- **멈추지 않는 동작**: 주먹처럼 "네 손가락 먼저 → 엄지" 순서가 필요한 자세에서 예전에는 0.25초 동안 `loop()`가 멈췄습니다.
  이제는 시간이 되면 엄지 단계를 보내는 방식이라 그 사이에도 새 명령과 무선 수신이 처리됩니다.
- **근전도 주먹(7)도 "네 손가락 먼저 → 엄지"** 로 움직입니다 (예전에는 동시에 움직여 엄지가 손가락 밑에 끼일 수 있었음).
  동시에 움직이게 하려면 자세 표에서 7번의 `PF_THUMB_LATE`를 지우면 됩니다.
- **호밍이 별도 태스크**: 호밍 중에도 무선이 살아 있고, 근전도 보드에 "호밍 중" 상태가 전달됩니다.
- **자세 표(`POSES`)**: 동작 추가·수정은 표 한 줄입니다.
- **상태 감시**: 서보 온도·전압·응답을 계속 확인해서 근전도 보드 LED와 양쪽 시리얼로 알립니다.
  전압 경고는 기본으로 꺼져 있습니다. 배터리에 맞게 `LOW_VOLT_DV`를 정하세요 (예: 2S 리튬이면 66 = 6.6V).
- **시리얼 입력**: 예전에는 숫자를 입력할 때마다 `parseInt()`가 최대 1초 동안 `loop()`를 멈췄습니다. 줄 단위 입력으로 바꿨습니다.
- 쓰이지 않던 코드(PC GUI용 바이너리 프로토콜, 토크 모드 소프트 리밋)는 뺐습니다. 호밍 코드(`Homing.cpp`)는 손대지 않았습니다.

## 8. 새로 학습할 때

```bash
python training/train_v2.py --cv
```

- 녹화 방법과 CSV 형식은 예전과 같습니다 (`emg_board_v2`의 `MODE_RECORD` + 수집 GUI).
- `output_v2/report.txt`에 결과가 저장되고, `emg2_model.h`와 `emg2_test_vectors.h`가 `firmware/emg_board_v2`에 복사됩니다.
- 그다음 PC에서 펌웨어 코드와 일치하는지 확인:

```bash
python training/host_check.py
```

(C++ 컴파일러가 없으면 `pip install ziglang`. 또는 보드에 `MODE_SELFTEST`로 올려서 확인)
